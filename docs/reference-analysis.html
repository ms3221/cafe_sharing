01핵심 결론

  1. 국내 경쟁사는 전부 "통이미지 상세", 해외 레퍼런스는 "HTML 섹션 상세" 와드프렌즈(아임웹), 엑스포디움(카페24), 현재 OUTDO 모두 긴 이미지 한 장~여러 장. Velites · Nike는 갤러리 + 아코디언 + 기능 카드 + 비교표 + FAQ를 HTML로 쌓음 → 검색 · 수정 · 모바일 가독성에서 차이가 큼.
  2. Velites가 가장 가까운 정답지 같은 카테고리(리프팅 벨트, 그립, 니슬리브), 비슷한 가격(€49.99 ≈ 브리즈 벨트 48,000원). 컬러 스와치 · 기능 카드 5개 · 모델 비교표 · FAQ 12개 구조를 그대로 차용 가능.
  3. 360° 회전 뷰는 열어본 레퍼런스 어디에도 없음 Velites도 4컷 갤러리 + 영상. 와드프렌즈도 각도별 정지컷. → 국내 크로스핏 장비 시장에서 OUTDO만의 차별 포인트가 될 수 있음. 단, 회전 촬영(24~36컷) 필요.
  4. 소재 클로즈업은 "영상 대신 사진 + 기술명 카드"로 해결 가능 Nike SKIMS "컬렉션 가이드"가 원단 클로즈업 사진 + 소재명 + 한 줄 설명. 휘영이 원한 "지켜보지 않아도 되는" 방식의 실제 예.
  5. 핀 19개는 4갈래로 정리됨 ① 구조도 · 스펙 도식 ② 다각도 모델컷 ③ 소재 · 재료 스와치 ④ 브랜드 감도(에디토리얼/카피). 이전 브리프의 추정 분류 중 6개가 실제와 달라 정정함(아래 핀 섹션 참고).
